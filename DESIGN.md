# Documentation design

Reference: https://www.docs.moi/alinma-pdf.html (2026-11-02).

Read mode. Geist 400/500/600 and Geist Mono 400/500/600 embedded from the reference's public CSS. Chinese fallback: Microsoft YaHei / PingFang SC. Canvas #fafafa, surface #fff, ink #171717, body #4d4d4d, caption #6b6b6b, rule #ebebeb, link #0070f3. Title 48/52, section 32/40, body 16/26, table 14/22. Preserve all document routes, media and diagram relationships. Technical acronyms retain their standard spelling; named features use Title Case. Tables and wide figures scroll locally on small screens. No global title-case transform.

Layout refinement: prose, lists, summaries, and source media share a responsive 940px maximum width. Media section headings have a 12px gap to their first asset; preserve source image pixels and list indentation.

Diagram readability: minimum 14px for diagram labels, descriptions, counters and links; 16px/1.5 node titles. Numbered flows reflow to 3/2/1 columns. Architecture retains local horizontal scrolling. FAQ cards use 24px padding and responsive columns.

Approved navigation cards (2026-11-03): inset 16:9 thumbnails, white surface, #e8e8e8 border, 14px corners, 16px padding, 18px titles and 14px two-line descriptions. At full document width the six overview cards form two rows of three. Two/four cards use two columns; one card is capped at 460px. Container widths below 760px/520px switch to two/one columns. Public docs and editor preview share the same stylesheet. Preserve all original links and media.

Localized professional workflow guides (2026-11-03): five diagram subjects in Chinese and English are attached to recording schedules, Playback overview, user role settings, alarm triggering flow and evidence export. Each guide adds prerequisites, operating/verification guidance and completion or exception notes. Accessible inline SVG preserves 20px node titles/18px text with local horizontal scrolling and a separate full diagram view. IDs and notes are included in the page table of contents; public docs and editor previews share the same renderer. Existing screenshots, videos, routes, document data and V1 content are preserved. No deployment guarantees, automatic rule tuning or native redaction/encryption capability are asserted.

Workflow sizing update: all five workflow figures in both languages scale proportionally to the 940px document measure using their original viewBox. Embedded and full-page diagrams have no forced minimum width, cropping or internal scrollbars. Remove scroll instructions and redundant keyboard stops; retain the View Larger link for detailed reading.
