Detection Guide

The following 12 entries explain detection names used in this guide. The enabled list depends on the project and deployed library, including whether Fall Detection and Sleeping Detection are available. Select only detections exposed by your deployment. The illustrations describe visual reasoning; they are not product screenshots, fixed thresholds, or a list of additional configuration fields.

DetectionMonitoring Goal
Geo FencingMonitor a restricted area in the camera image.
People CountingUnderstand how many people are currently in a monitored area.
No-Mask DetectionReview visible mask absence where face covering is required.
Smoking DetectionReview suspected smoking in a designated no-smoking area.
Motion DetectionIdentify visible activity or change within a selected part of the image.
Line CrossingMonitor a defined boundary and the direction in which a target crosses it.
Facial DetectionLocate a visible face for review.
IDLE TimeReview a person remaining in a monitored area beyond the allowed dwell time.

Geo Fencing

Use Geo Fencing to review people or other supported targets entering or remaining in a restricted area. The fence is a region drawn in the video image; it does not represent a GPS boundary. A target must meet the deployed region rule during its active schedule.

01 / Observe

Outside the Region

A target approaches the configured boundary.

02 / Evaluate

Boundary Interaction

The target enters the selected region.

03 / Review

Qualifying Presence

The configured region rule is satisfied.

Set Up and Check: Draw the region around the actual restricted space. Exclude public walkways, reflections, and areas beyond the camera’s useful view. Configure direction and duration only where the selected rule provides those controls.

Interpret the Result: Check the target’s position before and after the boundary interaction. A target already visible inside the region does not, by itself, establish when entry occurred.

People Counting

Use People Counting to assess the number of people visible within a defined region. The same person moving within the region should remain one observed occupant. Area occupancy and cumulative entry or exit totals answer different questions; use the interpretation supported by the deployed counting rule.

01 / Observe

Current Occupants

Two people are visible inside the region.

02 / Evaluate

New Arrival

A third person enters the monitored region.

03 / Review

Current Count

Movement within the region does not add a person.

Set Up and Check: Select a region where people remain distinguishable and check the camera angle, occlusion, and lighting. Set a people-count threshold when the selected rule exposes that setting. Do not treat an illustrative count in the diagram as a recommended limit.

Interpret the Result: Compare the observed count with the scene as people enter, remain, and leave. Passage totals, where supported, do not identify unique individuals.

No-Mask Detection

Use No-Mask Detection in a defined area and monitoring period where people are required to wear masks. The rule evaluates whether a sufficiently visible face shows the required covering over the nose and mouth. Repeated usable observations help distinguish a persistent omission from a brief unusable view.

01 / Observe

Covered Face

The visible nose and mouth are covered.

02 / Evaluate

Visible Omission

An unobstructed face lacks the required mask.

03 / Review

Review the Condition

Usable observations retain the omission for review.

Set Up and Check: Choose a camera position that provides a useful view of faces. Apply the region and active schedule to the relevant work area. Configure any available confirmation interval according to the deployed rule.

Interpret the Result: Head rotation, hands, and other obstructions can prevent a reliable observation. A visible mask does not establish its filtration performance or effectiveness.

Smoking Detection

Smoking Detection evaluates visible smoking-related objects together with hand-to-mouth interaction over time. A repeated interaction involving a supported smoking-device candidate provides more useful evidence than a hand near the face in a single frame. Treat the result as suspected smoking that requires review.

01 / Observe

Object Candidate

A narrow object is visible near the hand.

02 / Evaluate

Hand-to-Mouth Interaction

The object moves toward the mouth.

03 / Review

Suspected Episode

Repeated contextual cues support operator review.

Set Up and Check: Cover the relevant no-smoking area and confirm that the camera can resolve the object and the person’s hand and mouth. Use the supported schedule and trigger-duration controls where available.

Interpret the Result: Eating, drinking, and background smoke can resemble parts of the sequence. Do not assume that every tobacco product or electronic device is supported; check the deployed detection and review the associated footage.

Motion Detection

Use Motion Detection when the monitoring task concerns movement in a region rather than a particular behavior. The rule evaluates visible changes over time within the configured area. A motion observation alone does not establish that a person entered a restricted area, crossed a line, or performed a specific action.

01 / Observe

Reference View

Observe the monitored part of the scene.

02 / Evaluate

Visible Change

A moving subject changes the image.

03 / Review

Review the Activity

Check the source of the visible movement.

Set Up and Check: Restrict the region to the relevant scene and apply the required schedule. Use duration and other controls only when they are provided by the selected rule. Test both expected activity and normal background movement.

Interpret the Result: Lighting changes, shadows, reflections, moving foliage, and camera movement can create visible change. Review the footage and use a more specific supported detection when the task requires a semantic event.

Line Crossing

Line Crossing evaluates a tracked target moving from one side of a finite virtual line to the other. The observed trajectory must cross the configured line segment. Being close to the line or first appearing on one side does not establish a crossing.

01 / Observe

Starting Side

A target is observed on one side of the line.

02 / Evaluate

Crossing Path

Its trajectory intersects the finite line.

03 / Review

Opposite Side

The continued track confirms the crossing.

Set Up and Check: Place the line across the relevant passage and ensure that both sides remain visible. Select Entry, Exit, or Both Directions where the rule provides those options, and verify the direction against actual movement at the site.

Interpret the Result: Check the sequence before and after the crossing. Occlusion, a line extending beyond the usable scene, or repeated back-and-forth movement can affect interpretation; validate how the deployed rule handles repeated crossings.

Facial Detection

Facial Detection identifies a usable facial region in the camera image. Face size, visibility, lighting, and image quality affect whether the region can be evaluated. The result establishes face presence; it does not, by itself, identify a person or verify access authorization.

01 / Observe

Face Enters View

A person moves into the usable camera view.

02 / Evaluate

Locate the Facial Region

Visible detail supports face localization.

03 / Review

Confirm Face Presence

Review the observed facial region.

Set Up and Check: Choose an angle and distance that preserve useful facial detail. Keep the relevant area visible and use only the face-specific controls exposed by the deployed detection.

Interpret the Result: Inspect the localized facial region in its scene context. A profile view, face covering, backlighting, or occlusion can limit the observation. Keep face detection distinct from face recognition or identity matching.

IDLE Time

IDLE Time concerns a person’s dwell time in a defined region. A maintained track provides evidence that the same observed person remains in the area over the monitoring interval. Movement within the region can still count as continued presence; this label does not describe equipment idle time.

01 / Observe

Presence Begins

A person enters the timed region.

02 / Evaluate

Presence Continues

The maintained track remains inside.

03 / Review

Dwell Allowance Exceeded

Continued presence exceeds the configured allowance.

Set Up and Check: Draw the region around the relevant waiting or restricted space and configure the dwell interval where the deployed rule supports it. Distinguish a dwell allowance from the separate VA Trigger Duration setting; do not assume they are interchangeable.

Interpret the Result: Check the start of presence, the continued track, and any exits or occlusion gaps. Confirm how the deployed rule treats reentry and interrupted observations before interpreting an excessive-dwell event.

Fire Detection

Fire Detection evaluates visible flame appearance and its development over time. A persistent flame-like region provides more context than a single bright area. The observation concerns visible fire evidence in the image; it does not establish combustion chemistry or detect a hidden fire outside the camera view.

01 / Observe

Flame-Like Appearance

A small flame-like region becomes visible.

02 / Evaluate

Persistence and Development

The visible region continues over time.

03 / Review

Review Visible Fire Evidence

The qualifying observation is reviewed in context.

Set Up and Check: Cover the relevant risk area and examine any legitimate flame sources within it. Apply regions, schedules, exclusions, and confirmation controls only to the extent supported by the deployed rule.

Interpret the Result: Review the surrounding sequence for persistent flame characteristics and scene context. Reflections, bright lighting, welding, or permitted flames may require closer inspection. Fire Detection does not by itself establish that a separate smoke-detection capability is active.

Crowd Detection

Crowd Detection can identify a crowding condition when the observed number of people meets the deployed threshold rule for the required interval. Use it to review continued occupancy beyond the intended limit. A single busy frame does not establish persistent overcrowding, and crowding is different from a group forming.

01 / Observe

Below the Limit

The example starts with three visible people.

02 / Evaluate

Count Increases

New arrivals raise the observed count.

03 / Review

Crowding Persists

The configured count condition persists over time.

Set Up and Check: Define the monitored region, people-count threshold, and duration where those controls are supported. Use a count threshold as a number of people; do not describe it as people per square meter without an established spatial calibration.

Interpret the Result: Check visibility, occlusion, arrivals, and departures over the relevant interval. Distinguish a temporary passage through the scene from a sustained crowding condition.

Fall Detection

Fall Detection evaluates a sequence in which a person descends and changes posture relative to the floor or another supporting surface. The preceding posture and the observed transition help distinguish a possible fall from a person simply being low in the image. A fall need not be rapid or followed by prolonged immobility.

01 / Observe

Initial Posture

The person and supporting floor are visible.

02 / Evaluate

Observed Descent

Body height and orientation change.

03 / Review

Review a Possible Fall

The descent and low posture are reviewed together.

Set Up and Check: Use a view that shows the person and the supporting surface. Apply the relevant region and schedule only when this detection is available in the deployed library. Validate with suitable recorded examples rather than staging a dangerous movement.

Interpret the Result: Check the preceding frames and the subsequent scene. Sitting, kneeling, or picking up an object can resemble parts of the sequence. A person first observed on the floor does not establish that the preceding fall was seen.

Sleeping Detection

Sleeping Detection combines persistent visual cues such as a lowered head, slumped posture, and reduced activity during an active duty period. A sustained combination of cues can support a possible-sleep event for review. Inactivity alone does not establish that a person is asleep.

01 / Observe

Active Attendance

An upright worker is visible at the workstation.

02 / Evaluate

Posture Changes

The head lowers and the seated posture slumps.

03 / Review

Review Persistent Cues

Posture and reduced activity persist together.

Set Up and Check: Use a camera angle that shows the relevant workstation and posture. Limit the active schedule to periods requiring attendance and account for authorized rest. Configure any confirmation duration only if the deployed rule provides it.

Interpret the Result: Compare the posture and activity before and during the observation. Reading, looking down, or a briefly lowered head may resemble sleep indicators. The event is a visual observation for human review, not a clinical determination of sleep.

Reference: Video Analytics Explainers. Geo Fencing maps to Restricted Area Intrusion Detection; People Counting to Area Occupancy Counting; Facial Detection to Face Detection; IDLE Time to Excessive Dwell Time Detection; Crowd Detection to Overcrowding Detection; and Sleeping Detection to Sleep-on-Duty Detection. No-Mask Detection, Smoking Detection, Line Crossing, Fire Detection, and Fall Detection use their matching entries. Motion Detection has no standalone entry on the reference page; its explanation follows the existing product documentation.

检测说明

以下说明覆盖本指南中的 12 个检测名称。可用列表取决于项目及已部署的检测库，跌倒检测和睡岗检测是否可用也应以实际部署为准。仅选择当前部署中可启用的项目。配图用于说明视觉判断过程，不代表实际界面、固定阈值或新增配置项。

检测名称监测目标
地理围栏（Geo Fencing）监测相机画面中受限区域的进入或停留。
人员计数（People Counting）了解监测区域内当前可见的人员数量。
未佩戴口罩检测（No-Mask Detection）在要求佩戴口罩的区域核查可见的未佩戴情况。
吸烟检测（Smoking Detection）在指定禁烟区域核查疑似吸烟行为。
视频动态检测（Motion Detection）发现画面指定区域内可见的活动或变化。
越线检测（Line Crossing）监测目标是否跨越指定边界及其通行方向。
人脸检测（Facial Detection）在画面中定位可见的人脸区域以供核查。
停留超时检测（IDLE Time）核查人员在指定区域的停留是否超过允许时长。
火焰检测（Fire Detection）核查监测画面中可见的疑似火焰活动。
人群检测（Crowd Detection）核查指定人数限制区域内持续存在的拥挤情况。
跌倒检测（Fall Detection）核查人员相对于地面等支撑面的下降及姿态变化。
睡岗检测（Sleeping Detection）核查要求在岗活动期间的疑似睡眠状态。

地理围栏（Geo Fencing）

地理围栏用于核查人员或其他受支持目标是否进入或停留在指定管控区。围栏是在视频画面中绘制的区域，不是 GPS 地理边界。目标需要在规则生效时段内满足当前部署的区域规则。

01 / 观察

区域外接近

目标接近已配置的区域边界。

02 / 判断

与边界交互

目标从外部进入选定区域。

03 / 复核

满足区域规则

区域内的目标状态符合当前规则。

配置与验证： 沿实际管控空间绘制区域，排除公共通道、反光位置及画面中无法有效观察的部分。只有当前规则提供相应选项时，才配置检测方向和持续时间。

结果解释： 对比目标与区域边界交互前后的画面。目标首次出现时已在区域内，并不能单独证明其进入时间。

人员计数（People Counting）

人员计数用于评估指定区域内可见的人数。同一人员在区域内移动，不应被当作新增人员。区域当前人数与累计进入、离开次数回答的是不同问题，应以当前部署的计数规则为准。

01 / 观察

观察当前人数

区域内可见两名人员。

02 / 判断

识别新增人员

第三名人员进入监测区域。

03 / 复核

保持正确计数

原有人员在区域内移动不增加人数。

配置与验证： 选择能清楚区分人员的区域，检查拍摄角度、遮挡和光照。当前规则提供人数阈值时再设置该项。示意图中的人数仅用于解释原理，不是建议阈值。

结果解释： 在人员进入、停留和离开时，将计数与实际画面对照。受支持规则中的通行次数也不等于不同身份的独立人数。

未佩戴口罩检测（No-Mask Detection）

未佩戴口罩检测用于有明确口罩要求的区域和时段。规则根据可用的人脸画面，判断鼻部与口部是否存在要求的遮盖。连续可用的观察有助于区分持续未佩戴与短暂无法判断的画面。

01 / 观察

观察遮盖状态

可见的鼻部与口部由口罩遮盖。

02 / 判断

观察未佩戴情况

无遮挡的人脸缺少要求的口罩。

03 / 复核

核查持续状态

保留可用的未佩戴观察供人员复核。

配置与验证： 选择能够有效观察人脸的拍摄位置，将区域和生效排期限定在相关工作场所。只有已部署规则提供确认时长时，才按现场需求设置。

结果解释： 转头、手部或其他物体遮挡可能使结果无法可靠判断。画面中存在口罩，不代表已验证其过滤性能或防护效果。

吸烟检测（Smoking Detection）

吸烟检测结合可见的相关物体与持续的手口交互判断疑似行为。与单帧中手靠近人脸相比，受支持吸烟器具候选物体的重复交互更有助于核查。检测结果应作为疑似吸烟事件，由人员结合画面复核。

01 / 观察

观察候选物体

手部附近出现细长的候选物体。

02 / 判断

观察手口交互

物体随手部向口部移动。

03 / 复核

核查疑似吸烟

结合重复动作与上下文进行复核。

配置与验证： 覆盖相关禁烟区域，确认画面能够分辨物体以及人员的手部和口部。当前规则支持时，再配置生效排期和触发时长。

结果解释： 进食、饮水以及背景烟雾可能与部分动作相似。不要假定所有烟草制品或电子器具都受支持，应核对已部署检测并查看关联录像。

视频动态检测（Motion Detection）

当监测目标是区域中的运动，而非某一种具体行为时，可使用视频动态检测。规则关注配置区域在一段时间内的可见变化。仅有动态变化，并不能证明人员进入管控区、跨越检测线或实施了某种行为。

01 / 观察

观察监测画面

确认需要观察的场景范围。

02 / 判断

发现可见变化

移动目标引起区域内画面变化。

03 / 复核

核查活动来源

结合前后画面判断变化原因。

配置与验证： 将检测区域限定在有关场景，并配置所需生效时段。仅使用当前规则实际提供的触发时长或其他选项，同时测试预期活动和正常背景变化。

结果解释： 光照变化、阴影、反光、树叶摆动和相机移动均可能形成画面变化。结合录像判断运动来源；需要判断特定行为时，应选择已支持的对应检测。

越线检测（Line Crossing）

越线检测判断受跟踪目标是否从有限长度虚拟线的一侧移动到另一侧。观察到的轨迹需要穿过实际配置的线段。靠近检测线，或首次出现在某一侧，都不能单独证明已经越线。

01 / 观察

确认起始侧

目标先出现在检测线的一侧。

02 / 判断

观察跨线轨迹

移动轨迹与配置线段相交。

03 / 复核

确认到达另一侧

连续轨迹支持本次越线判断。

配置与验证： 将检测线放在实际通道上，并确保两侧均可观察。规则提供相应选项时，选择进入、离开或双向，并用现场实际移动核对方向。

结果解释： 查看越线前后的连续画面。遮挡、检测线超出有效画面或目标反复往返均可能影响解释，应验证当前规则对重复越线的处理。

人脸检测（Facial Detection）

人脸检测用于发现相机画面中可用的人脸区域。人脸大小、可见程度、光照和图像质量会影响能否进行判断。结果表示存在人脸，本身不确认人员身份，也不验证其访问授权。

01 / 观察

人脸进入画面

人员移动到相机可用视野内。

02 / 判断

定位人脸区域

可见细节支持定位面部范围。

03 / 复核

确认存在人脸

核查画面中的人脸区域。

配置与验证： 选择能保留足够人脸细节的角度与距离，保持相关区域可见，并仅使用已部署检测实际提供的人脸相关配置。

结果解释： 结合场景核查定位的人脸区域。侧脸、面部遮盖、逆光和遮挡可能限制观察。应将人脸检测与人脸识别、身份比对明确区分。

停留超时检测（IDLE Time）

IDLE Time 关注人员在区域内的停留时间。连续的跟踪证据用于支持同一观察目标在一段时间内持续处于区域中的判断。人员在区域内移动仍可能属于持续停留；此名称不表示设备空闲时间。

01 / 观察

开始观察停留

人员进入需要计时的区域。

02 / 判断

保持连续观察

同一目标持续处于区域内。

03 / 复核

超过停留时限

持续停留超出已配置的允许时间。

配置与验证： 围绕相关等候区或管控空间绘制区域。已部署规则支持时，再配置停留时限。停留允许时长与 VA 触发时间是不同概念，不应默认两者可相互替代。

结果解释： 核查开始停留、持续跟踪以及中途离开或被遮挡的情况。解释超时事件前，应确认当前规则如何处理重新进入和观察中断。

火焰检测（Fire Detection）

火焰检测结合可见火焰的外观及其随时间的发展进行判断。持续出现的疑似火焰区域，比单帧亮斑提供更多上下文。观察范围是图像中的可见火情证据，并不判断燃烧物质，也无法据此发现相机视野之外的隐蔽火情。

01 / 观察

出现疑似火焰

画面中出现小范围火焰样区域。

02 / 判断

持续观察发展

可见区域在一段时间内持续出现。

03 / 复核

核查可见火情

结合上下文复核满足条件的观察。

配置与验证： 覆盖相关风险区域，并检查其中是否存在合法明火。仅按当前部署规则支持的范围使用区域、排期、排除项和确认条件。

结果解释： 回看前后画面中的持续火焰特征及现场背景。反光、强光、焊接或允许的明火可能需要进一步核查。启用火焰检测，并不等于已启用独立的烟雾检测能力。

人群检测（Crowd Detection）

人群检测可在观察人数满足当前阈值规则并持续达到要求时长时，识别需要核查的拥挤状态。单帧中人员较多，并不能单独证明持续过度拥挤；拥挤状态也不同于人员形成聚集群体的过程。

01 / 观察

观察初始人数

示例开始时可见三名人员。

02 / 判断

观察人数增加

新增人员使区域内观察人数上升。

03 / 复核

核查持续拥挤

人数条件持续达到当前规则要求。

配置与验证： 按已支持的选项配置监测区域、人数阈值和持续时间。人数阈值表示人员数量；没有建立空间标定时，不应将其表述为每平方米人数。

结果解释： 检查相关时段的可见性、遮挡以及人员进入和离开情况，区分短暂穿行与持续拥挤。

跌倒检测（Fall Detection）

跌倒检测关注人员下降并相对于地面或其他支撑面改变姿态的过程。此前姿态与实际观察到的变化，有助于区分疑似跌倒和单纯处于画面低位。跌倒不一定发生得很快，也不一定伴随长时间不动。

01 / 观察

观察起始姿态

人员与支撑地面均在画面内。

02 / 判断

观察下降过程

身体高度与朝向发生变化。

03 / 复核

核查疑似跌倒

结合下降过程和低位姿态复核。

配置与验证： 选择同时能观察人员和支撑面的视角。只有已部署检测库提供此项时，才配置相关区域与生效排期。使用适当的已有录像验证，不应通过危险动作演示。

结果解释： 查看此前画面和后续现场状态。坐下、跪下或弯腰拾物可能与部分过程相似。首次看到人员已在地面上，并不能证明此前跌倒过程已被观察到。

睡岗检测（Sleeping Detection）

睡岗检测结合低头、身体前倾或伏靠以及活动减少等持续视觉线索进行判断。多项线索持续出现时，可支持生成供核查的疑似睡岗观察。仅凭静止不动，不能确定人员已经入睡。

01 / 观察

观察在岗状态

工位内可见保持坐姿的人员。

02 / 判断

观察姿态变化

头部降低，坐姿出现前倾或伏靠。

03 / 复核

核查持续线索

姿态变化与活动减少持续出现。

配置与验证： 选择能观察相关工位和身体姿态的角度，将生效排期限定在要求在岗的时段，并考虑允许休息的安排。仅在当前规则提供确认时长时配置该项。

结果解释： 对比观察前后及观察期间的姿态与活动。阅读、向下查看或短暂低头可能与睡眠线索相似。此类事件供人工复核，不是医学上的睡眠判定。

参考：视频分析原理说明。Geo Fencing 对应受限区域入侵检测，People Counting 对应区域人数统计，Facial Detection 对应人脸检测，IDLE Time 对应停留超时检测，Crowd Detection 对应过度拥挤检测，Sleeping Detection 对应睡岗检测。未佩戴口罩、吸烟、越线、火焰及跌倒检测采用对应条目。参考页没有独立的视频动态检测条目，该项按现有产品文档说明。
